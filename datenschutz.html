Datenschutzerklärung

Diese Seite beschreibt, wie die Chrome-Erweiterung Babbel Export mit Nutzerdaten umgeht. Diese Erklärung gilt für die Erweiterung, wie sie im Chrome Web Store veröffentlicht wird.

Alleiniger Zweck

Die Erweiterung dient ausschließlich dazu, persönliche Lernfortschrittsdaten von Babbel zu extrahieren und dem Nutzer als lokale Datei (z. B. CSV oder JSON) zum Herunterladen bereitzustellen.

Welche Daten werden verarbeitet

  • Website-Inhalte (Babbel): Beim Export werden nur die sichtbaren Daten von Babbel-Seiten gelesen (z. B. Kurs-/Lektionsnamen, Fortschrittsanzeigen, Zeitstempel), die zum Erstellen der Exportdatei notwendig sind.
  • Einstellungen: Optional werden nur lokal in der Erweiterung gespeicherte Einstellungen (z. B. bevorzugtes Exportformat) in chrome.storage gehalten.
  • Es werden keine Daten an einen externen Server gesendet.

Berechtigungen und Begründung

  • storage: Wird verwendet, um Benutzer‑Einstellungen lokal zu speichern (z. B. Exportformat). Daten bleiben lokal in Ihrem Browser.
  • scripting: Erforderlich, um das Skript zur Extraktion der Seite in die aktive Babbel‑Seite zu injizieren; das geschieht nur auf Ihre ausdrückliche Aktion (z. B. Klick auf "Export").
  • activeTab: Erlaubt das temporäre Ausführen von Code in dem Tab, den Sie aktiv ausgewählt haben — nur nach Ihrer Interaktion mit der Erweiterung.
  • Hostberechtigung (https://*.babbel.com/*): Erforderlich, damit die Erweiterung die auf Babbel sichtbaren Inhalte lesen kann, um einen gültigen Export zu erzeugen. Die Berechtigung wird ausschließlich für die Domänen von Babbel genutzt und nur wenn Sie den Export auslösen.

Remote Code

Die Erweiterung lädt keinen JavaScript- oder WebAssembly-Code von externen Servern nach. Alle ausführbaren Dateien sind im Erweiterungspaket enthalten. Es wird kein Remote Code verwendet.

Weitergabe und Verkauf von Daten

Es werden keinerlei Nutzerdaten verkauft oder an Dritte weitergegeben, außer wenn dies zur Erfüllung des alleinigen Zwecks technisch erforderlich ist (z. B. lokale Datei‑Erstellung). Es werden keine Daten für andere Zwecke verwendet (z. B. Werbung, Bonitätsprüfung).

Datenspeicherung und -löschung

Alle persistierten Daten (Einstellungen) liegen lokal im Browser (chrome.storage) und können vom Nutzer jederzeit über die Erweiterungsoptionen oder durch Deinstallation gelöscht werden. Exportierte Dateien werden nur auf dem Gerät des Nutzers gespeichert, wenn der Nutzer den Download bestätigt.

Sicherheit

Es werden angemessene Maßnahmen ergriffen, um die im Browser gespeicherten Daten vor unbefugtem Zugriff zu schützen. Die Erweiterung überträgt jedoch keine Daten an externe Server, wodurch Angriffsflächen reduziert werden.
