Privacy Policy

Deutsche Version: Datenschutzerklärung

This page describes how the Chrome extension Babbel Export handles user data. This policy applies to the extension as published in the Chrome Web Store.

Single Purpose

The extension's sole purpose is to extract a user's learning progress data from Babbel and provide it to the user as a local file (e.g. CSV or JSON) for download.

Data Processed

  • Website content (Babbel): On export, the extension reads only the visible content on Babbel pages necessary to produce the export (e.g., course/lesson names, progress values, timestamps).
  • Settings: Optionally, only local settings (e.g. preferred export format) are stored in chrome.storage.
  • No data is sent to external servers.

Permissions and Justification

  • storage: Used to persist user preferences locally (e.g. export format). Data stays in the user's browser.
  • scripting: Required to inject a script into the active Babbel page on user request to read visible content for export.
  • activeTab: Allows temporary execution in the currently active tab after a direct user action.
  • No host permissions are requested. The extension only works on the active tab after a direct user action.

Remote Code

The extension does not load JavaScript or WebAssembly code from external servers. All executable code is included in the extension package. No remote code is used.

Disclosure and Sale of Data

No user data is sold or disclosed to third parties, except in cases strictly required for the single purpose (e.g., creating a local file). No data is used for other purposes such as advertising or credit checks.

Storage and Deletion

Persisted data (settings) is stored locally in the browser (chrome.storage) and can be deleted by the user via the extension options or by uninstalling the extension. Exported files are only saved to the user's device when the user confirms the download.

Security

Reasonable measures are taken to protect stored data in the browser from unauthorized access. The extension does not transmit data to external servers, reducing attack surface.

Changes to this Privacy Policy

Changes to this privacy policy will be posted on this page. Users should review this page periodically.
